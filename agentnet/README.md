# AgentNet — Cyberpunk AI Dashboard

Four autonomous AI agents managing your Etsy, Shopify, Social Media and Email — running 24/7 in a live 3D cyberpunk city.

## Deploy in 3 minutes (Vercel — free)

### Option A: Drag & Drop (fastest)
1. Go to vercel.com → sign up free
2. Click "Add New Project" → "Deploy without Git"
3. Drag this entire folder onto the page
4. Click Deploy
5. Done — live URL in 30 seconds

### Option B: GitHub (auto-deploys on every update)
1. Push this folder to a GitHub repo
2. Go to vercel.com → "Add New Project"
3. Import your GitHub repo
4. Click Deploy
5. Every future push auto-deploys

### Option C: Netlify
1. Go to netlify.com → sign up free
2. Drag this folder onto the Netlify dashboard
3. Done

## First time setup
When you open the app, it will ask for your Anthropic API key.
- Get one free at console.anthropic.com
- Your key is stored in your browser only — never sent anywhere except Anthropic's API

## What the agents do
- **Etsy Agent** — writes listings, researches trends, audits SEO, suggests pricing
- **Shopify Agent** — writes cart recovery emails, optimises product pages, creates discount strategies
- **Social Agent** — scripts TikTok hooks, writes Instagram captions, builds hashtag sets, plans content
- **Email Agent** — writes campaigns, crafts subject lines, builds welcome sequences

Agents run autonomously in the background. Click any agent in the bottom bar to chat with them directly.

## Controls
- Click an agent in the bottom bar to open their command panel
- Click directly on an agent character in the 3D world to open their panel
- Type commands in the chat input or use the quick action buttons
- The minimap (top right) shows real-time agent positions
